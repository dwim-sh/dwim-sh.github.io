Interface

An interactive shell.
A scriptable tool.

With no arguments, dwim starts an interactive session in the current directory. Given a prompt, it answers and exits.

~/src/project
$ dwim
$ dwim "Add a regression test for this bug."
$ dwim "Explain the locking here." > locking.md
One program

One program.
Nothing else to install.

The harness and the inference engine are one Rust binary, with no Python and no separate runtime. To run the model locally, it needs a Mac with 32 GiB of memory, or a Linux GPU with 24 GB of VRAM.

Integrations

dwim runs inference locally or using a cloud provider. Locally, it downloads the model from Hugging Face on first use. In the cloud, it runs the model at Cerebras, OpenRouter, or Vercel's AI Gateway. Pick a provider with /provider, and then the model with /model.
