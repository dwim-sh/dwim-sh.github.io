A coding agent that runs on your own GPU.

A coding agent that runs on your device. No account, no API key, no token bill, and your code never leaves your system.

macOS on Apple silicon · Linux with a Vulkan GPU · MIT

Warning

dwim is experimental software. Expect bugs, rough edges, and changes that break things from one commit to the next. The model runs shell commands on your machine without asking first, so use it on code you have committed or backed up.

Nothing leaves your machine.

The model runs on your GPU, so your code, your prompts, and whatever is in your .env stay where they are. It works on a plane, on code you are not allowed to upload, and the thousandth question costs what the first did.

Give it a prompt on the command line and the reply is all that comes out on standard output, so it slots into a script like any other tool.

$ dwim "What changed in the last commit? One sentence."
The last commit changed the CLI so the shell stops drawing a bullet line while a reply still has no text yet (e.g., while the model is in a thought, writing blank lines, or executing a tool call), which previously left a bare bullet until the text or tool call arrived.

A 27B model that fits on your GPU.

dwim ships with Bonsai 2 27B: Qwen3.8-27B with every weight compressed to -1, 0, or 1 by PrismML. The model takes 6 GB instead of 54, which is what puts 27 billion parameters on a laptop.

It thinks before it answers, calls tools to read files and run commands, and follows your project's AGENTS.md.

Will it run on my machine?

Probably. The model needs about 6 GB of memory on the device, plus room for the conversation. The session at the top of this page ran on an 8 GB AMD card from 2019.

Something older or smaller can still run it on the CPU with --device cpu, slowly.

Requirements

  • A GPU with at least 8 GiB of VRAM.
  • Linux or macOS as the operating system.
  • 6 GiB of disk space for the model.
